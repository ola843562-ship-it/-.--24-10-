Установка:
Для установки программы необходимо скачать архив File_manager7.z и распаковать его в любое удобное для вас место, затем найти в нём файл my_file_manager.exe и щёлкнуть по нему дважды, после чего программа запустится.
Особенности работы:
Программа не работает с файлами, находящимися на OneDrive.
Для корректного отклика клавиш обязательна Английская раскладка
Программные функции:
Программа выводит название рабочей директории и список всех файлов и директорий в ней
Стрелочки перемещают курсор вверх и вниз
По нажатию 'enter' программа выводит содержимое данной директории и делает её рабочей
По нажатию 'backspace' программа возвращает пользователя в родительскую директорию
При нажатии 'DEL' программа удаляет файл, на котором находится курсор. Удаление требует подтверждения. При нажатии клавиши выводится строка подтверждения с функциями y- подтвердить и n-отменить.
При нажатии пробела или 'm' программа ставит отметку на файле и запоминает его, пока не выделен следующий
При нажатии 'c' программа копирует отмеченный элемент в текущую рабочую директорию
При нажатии 'x' программа перемещает отмеченный элемент в текущую рабочую директорию
При нажатии 'o' программа выводит содержимое выделенного файла, переходя в режим чтения. По нажатии 'esc' программа возвращается в режим работы с файлами.
При нажатии 'i' программа переходит в режим подробного отображения.
Нажатие 'esc' или 'q' закрывает программу.
